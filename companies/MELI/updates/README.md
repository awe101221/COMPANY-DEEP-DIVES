# MELI Intelligence Updates

Store dated incremental research reports in this directory using the filename format:

`YYYY-MM-DD.md`

Each report should include:

1. Bottom line.
2. New verified developments.
3. Financial or KPI impact.
4. Thesis impact.
5. Market expectations.
6. Risks and disconfirming evidence.
7. Deep-research finding.
8. Knowledge-base or model changes.
9. Open questions and next checks.
10. Sources and as-of time.

If no material development is identified, keep the report concise and do not manufacture a thesis change.
